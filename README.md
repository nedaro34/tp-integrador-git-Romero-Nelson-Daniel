# Cool Literato

## Descripción
Este proyecto conforma el sexto trabajo práctico de la Diplomatura en Desarrollo Web Full Stack con JavasCript dictada por el Nodo Tecnológico de la provincia de Catamarca, Argentina.

Dicho proyecto, fue reutilizado en este repositorio para formar parte del trabajo práctico integrador del cruso Introducción a Git y GitHub para la Gestión de Proyectos Digitales, dictado por la misma entidad educativa.

Este proyecto consiste en una pequeña landing page estática sobre escritores latinoamericanos.

## Objetivo
El objetivo de este repositorio fue desarrollado con el fin de practicar el uso de git. La landing page contenida aquí tuvo como finalidad practicar la estructuración de archivos html y la aplicación de estilos usando css.

La landing page fue alterada respecto a su versión original, ya que la versión inicial contaba únicamente con un archivo html que contenía css dentro de él, mientras que acá dichas tecnologías se encuentran en archivos separados para que el proyecto adquiera modularidad y sea más fácil de mantener.

## Estructura del repositorio
```
tp-integrador-git-Romero-Nelson-Daniel
    │───ENTREGA.md
    │───README.md
    │
    └───proyecto
        │───index.html
        │───styles.css
        │
        └───img
            │───borges-argentina.jpg
            └───favicon.png
```

`ENTREGA.md:` Funciona como un registro del trabajo realizado en este repositorio.

`README.md:` Contiene la información sobre el proyecto, la que estás leyendo en este preciso momento.

`index.html:` Es el archivo más importante de la landing page. Contiene la estructura de elementos html y la información contenida en ella.

`styles.css:` Estilos utilizados por index.html.

`img:` Carpeta que contiene las imágenes utilizadas en la landing page.
